Cài Booking Check Helper (Chrome) — bản 0.1.3

QUAN TRỌNG: dùng web
  https://duynghiep89-sudo.github.io/booking-check/
(không dùng Vercel nếu bản đó còn cũ)

1. Xóa extension cũ trong chrome://extensions
2. Giải nén ZIP → Load unpacked → chọn thư mục có manifest.json (version 0.1.3)
3. Mở link GitHub Pages ở trên → Ctrl+F5
4. Đợi dòng xanh "Extension đã kết nối"
5. Check — cửa sổ mở phải là trang landing (KHÔNG có số booking trên URL lúc mới mở)

Máy có source: Load unpacked
  ...\booking_check\extension
rồi bấm Reload trên extension.
