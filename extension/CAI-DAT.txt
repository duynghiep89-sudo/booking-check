Cài Booking Check Helper 0.2.0 (bản ổn định — parser lúc “tạm ổn rồi”)

Local (Playwright): KHÔNG cần extension
  http://localhost:5187/booking-check/
  npm run dev

Internet: cần extension
1. Giải nén ZIP → chrome://extensions → Developer mode → Load unpacked
2. Chọn thư mục có manifest.json (version 0.2.0)
3. Mở https://duynghiep89-sudo.github.io/booking-check/ → F5 → Check

Cửa sổ hãng mở landing SẠCH (không kèm số booking trên URL lúc mở).
