Cài Booking Check Helper (Chrome) — bản 0.1.1

1. Xóa bản extension cũ (nếu có) trong chrome://extensions
2. Giải nén ZIP ra thư mục cố định (ví dụ Desktop\booking-check-extension)
3. Chrome → chrome://extensions → bật Developer mode
4. Load unpacked → chọn thư mục CÓ file manifest.json
5. Mở https://booking-check-rho.vercel.app (hoặc localhost) rồi F5 mạnh (Ctrl+F5)
6. Trên trang phải thấy dòng xanh: "Extension đã kết nối"
7. Mới bấm Check — sẽ mở CỬA SỔ Chrome mới và thao tác trang hãng

Nếu vẫn báo chưa kết nối:
- Đúng trình duyệt Chrome (không dùng Edge/Firefox trừ khi cài riêng)
- Không mở web trong cửa sổ Ẩn danh (hoặc cho phép extension chạy ẩn danh)
- Bấm Reload trên extension rồi F5 lại trang web
